# Инструкция по установке и запуску

## Что это?

**MCP Reverse-Engineering Toolkit** — это инструмент, который позволяет ИИ-ассистенту (например, Claude, VS Code с Kilo) просматривать и взаимодействовать с любым веб-сайтом в вашем браузере.

Система состоит из двух частей:
1. **MCP Proxy** — программа на вашем компьютере (запускается один раз)
2. **JS Agent** — скрипт, который вы вставляете в консоль браузера на нужном сайте

---

## Шаг 1. Установка MCP Proxy

### Требования
- **Node.js** версии 18 или выше. [Скачать Node.js](https://nodejs.org/)
- Git (необязательно, но рекомендуется)

### Установка

```bash
# 1. Клонируйте репозиторий (или скачайте архив)
git clone <url-репозитория>
cd mcp-reverse-engineering-toolkit

# 2. Установите зависимости
npm install
```

---

## Шаг 2. Запуск MCP Proxy

```bash
npm start
```

Вы должны увидеть:
```
WebSocket server listening on ws://localhost:3101
MCP server listening on http://localhost:3100/mcp
Health check: http://localhost:3100/health
```

**Оставьте это окно терминала открытым** — пока MCP Proxy работает, ИИ-агент может общаться с вашим браузером.

---

## Шаг 3. Настройка ИИ-агента (VS Code + Kilo / Claude)

Ваш ИИ-агент должен быть настроен на подключение к MCP-серверу по адресу:

```
http://localhost:3100/mcp
```

Способ настройки зависит от вашего ИИ-агента:

**Для VS Code + Kilo:**
Добавьте в `kilo.json` или настройки MCP:

```json
{
  "mcpServers": {
    "mcp-reverse-engineering-toolkit": {
      "type": "streamable-http",
      "url": "http://localhost:3100/mcp"
    }
  }
}
```

**Для Claude Desktop:**
В файле конфигурации `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "mcp-reverse-engineering-toolkit": {
      "transport": "streamable-http",
      "url": "http://localhost:3100/mcp"
    }
  }
}
```

---

## Шаг 4. Подключение к сайту (вставить JS-агента)

Это нужно сделать **один раз** для каждого сайта, который вы исследуете.

1. Откройте нужный веб-сайт в браузере (Chrome, Edge, Firefox, Opera)
2. Нажмите `F12` (или `Ctrl+Shift+I` / `Cmd+Option+I`) чтобы открыть **Инструменты разработчика**
3. Перейдите на вкладку **Console** (Консоль)
4. Скопируйте весь код из файла `dist/js-agent-bundle.js` и вставьте его в консоль
5. Нажмите `Enter`

Вы должны увидеть в консоли:
```
[JS-Agent] Connected to MCP Proxy. Version: 0.1.0
```

Если видите эту надпись — всё работает! Теперь ИИ-агент может изучать сайт.

> **Примечание:** Если вы закрыли вкладку с сайтом или обновили страницу, нужно заново вставить JS-агента (шаг 4).

---

## Проверка что всё работает

Откройте в браузере: http://localhost:3100/health

Должны увидеть:
```json
{ "status": "ok", "wsClients": 1, "version": "0.1.0" }
```

Число `wsClients: 1` означает, что JS-агент подключен.

## Часто задаваемые вопросы

**В: Ничего не происходит после вставки скрипта**
О: Убедитесь что MCP Proxy запущен (шаг 2). Проверьте http://localhost:3100/health

**В: Ошибка "WebSocket connection to 'ws://localhost:3101/' failed"**
О: MCP Proxy не запущен. Вернитесь в терминал и выполните `npm start`

**В: Страница использует HTTPS, а WebSocket — ws:// (не wss://)**
О: Это нормально для localhost. ws://localhost работает без SSL

**В: Как остановить MCP Proxy?**
О: Нажмите `Ctrl+C` в терминале, где он запущен

**В: Что делать с результатами исследования?**
О: Создайте папку `study/<название-проекта>/` и складывайте туда все артефакты (снимки, скрипты, заметки)
